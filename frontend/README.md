# 听声无恙 - 声纹识别应用展示Demo

这是一个用于展示Android平台声纹识别应用功能的前端Demo页面。该应用使用声纹识别技术进行用户身份验证，能够有效防止伪装攻击。

## 功能特点

- **用户注册**：用户通过朗读随机8位数字录入个人声纹
- **声纹登录**：用户朗读随机8位数字进行身份验证
- **防伪装功能**：系统能够检测伪装语音并拒绝登录
- **安全验证**：区分非本人真实声音和伪装语音

## 技术栈

- React.js
- TypeScript
- Tailwind CSS

## 使用说明

1. 克隆仓库到本地
2. 安装依赖：`npm install`
3. 启动项目：`npm start`
4. 在浏览器中访问：`http://localhost:3000`

## 演示流程

### 注册

1. 点击"注册"标签
2. 输入用户名
3. 点击"开始录音"按钮
4. 朗读显示的8位随机数字
5. 点击"停止录音"按钮
6. 系统会进行声纹注册处理

### 登录

1. 点击"登录"标签
2. 输入用户名
3. 点击"开始录音"按钮
4. 朗读显示的8位随机数字
5. 点击"停止录音"按钮
6. 系统会进行声纹验证并显示结果

## 注意事项

本应用为展示Demo，实际声纹验证功能通过模拟实现，不包含真实的声纹识别算法。在实际应用中，声纹识别和防伪装识别需要复杂的算法支持。
